# Security Policy

Repository này chủ yếu chứa documentation tĩnh và cấu hình Mintlify, nhưng vấn đề bảo mật vẫn có thể xuất hiện ở dependency, script, external link hoặc cấu hình deploy.

## Báo cáo vấn đề

Không công khai credential, token, secret hoặc dữ liệu nhạy cảm trong Issue/PR.

Nếu phát hiện secret bị commit, dependency đáng ngờ, script có hành vi nguy hiểm hoặc cấu hình deploy có thể làm lộ dữ liệu, hãy thông báo riêng cho maintainer repository qua kênh liên hệ GitHub của repository trước khi công khai chi tiết khai thác.

## Không thuộc phạm vi

Lỗ hổng của Inertia.js framework hoặc Mintlify không nên được báo cáo như lỗ hổng của repository này. Hãy sử dụng security channel chính thức của dự án/sản phẩm tương ứng.
