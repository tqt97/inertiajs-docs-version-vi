Khi dùng Inertia, việc phân quyền tốt nhất nên được xử lý ở phía máy chủ trong các authorization policy của ứng dụng. Tuy nhiên, bạn có thể thắc mắc làm sao kiểm tra policy phân quyền từ bên trong page component Inertia khi không thể truy cập các helper phía máy chủ của framework.

Cách đơn giản nhất để giải quyết là truyền kết quả của các phép kiểm tra phân quyền dưới dạng props cho page component.

```php
class UsersController extends Controller
{
    public function index()
    {
        return Inertia::render('Users/Index', [
            'can' => [
                'create_user' => Auth::user()->can('create', User::class),
            ],
            'users' => User::all()->map(function ($user) {
                return [
                    'first_name' => $user->first_name,
                    'last_name' => $user->last_name,
                    'email' => $user->email,
                    'can' => [
                        'edit_user' => Auth::user()->can('edit', $user),
                    ]
                ];
            }),
        ]);
    }
}
```

## Tài liệu chính thức

Bài dịch này được đối chiếu từ [tài liệu Inertia.js v1 chính thức](https://inertiajs.com/docs/v1/advanced/authorization). Nếu có khác biệt do phiên bản hoặc cập nhật mới, hãy ưu tiên tài liệu chính thức làm nguồn tham chiếu.
