Một lợi ích khi dùng Inertia là bạn không cần hệ thống xác thực đặc biệt như OAuth để kết nối đến API. Vì dữ liệu được cung cấp thông qua controller và phục vụ từ cùng domain với JavaScript component, bạn không cần cấu hình CORS.

Thay vào đó, bạn có thể dùng bất kỳ hệ thống xác thực nào framework phía server cung cấp. Thông thường đây là cơ chế dựa trên session, chẳng hạn của Laravel.
