---
title: Phân quyền
---

Khi dùng Inertia, authorization nên được xử lý phía server trong authorization policy của ứng dụng. Tuy vậy, đôi khi bạn vẫn cần thực hiện kiểm tra quyền trong Inertia page component, nơi các helper phía server của framework không khả dụng.

Cách đơn giản nhất là truyền trực tiếp kết quả kiểm tra authorization vào page component dưới dạng prop.

```php
class UsersController extends Controller
{
    public function index()
    {
        return Inertia::render('Users/Index', [
            'can' => [
                'create_user' => Auth::user()->can('create', User::class),
            ],
            'users' => User::all()->map(function ($user) {
                return [
                    'first_name' => $user->first_name,
                    'last_name' => $user->last_name,
                    'email' => $user->email,
                    'can' => [
                        'edit_user' => Auth::user()->can('edit', $user),
                    ]
                ];
            }),
        ]);
    }
}
```

## Tài liệu chính thức

Bài dịch này được đối chiếu từ [tài liệu Inertia.js v3 chính thức](https://inertiajs.com/docs/v3/security/authorization). Nếu có khác biệt do phiên bản hoặc cập nhật mới, hãy ưu tiên tài liệu chính thức làm nguồn tham chiếu.
