Ứng dụng demo chính thức Inertia.js v3 là app [Kitchen Sink](https://demo-v3.inertiajs.com) toàn diện được xây bằng Laravel và Vue. App gồm một mini CRM với contact, organization, note, cùng các page trình diễn tính năng riêng cho form, navigation, data loading, prefetching, state management, layout, event, error handling và nhiều nội dung khác. Source code có trên [GitHub](https://github.com/inertiajs/demo-v3).

Demo được host trên [Laravel Cloud](https://cloud.laravel.com) và database reset vào mỗi nửa đêm. Vui lòng tôn trọng dữ liệu khi chỉnh sửa.
