Một thách thức phổ biến khi xây dựng ứng dụng một trang là làm mới asset của website khi chúng thay đổi. Inertia giúp việc này đơn giản bằng cách cho phép theo dõi phiên bản hiện tại của asset. Khi asset thay đổi, ở request tiếp theo Inertia sẽ tự động thực hiện một lần tải toàn bộ trang thay vì visit XHR.

## Cấu hình

Để bật cơ chế tự động làm mới asset, bạn cần cho Inertia biết phiên bản hiện tại của asset. Đây có thể là bất kỳ chuỗi tùy ý nào (chữ, số hoặc file hash), miễn là giá trị thay đổi khi asset được cập nhật.

Thông thường, phiên bản asset của ứng dụng có thể được chỉ định trong phương thức `version` của middleware Inertia `HandleInertiaRequests`.

```php
class HandleInertiaRequests extends Middleware
{
    public function version(Request $request)
    {
        return parent::version($request);
    }
}
```

Ngoài ra, bạn có thể cung cấp phiên bản asset thủ công bằng phương thức `Inertia::version()`.

```php
use Inertia\Inertia;

Inertia::version($version);
Inertia::version(fn () => $version); // Lazily...
```

## Cache busting

Cơ chế làm mới asset trong Inertia dựa trên giả định rằng một lần hard page visit sẽ khiến asset được tải lại. Tuy nhiên, bản thân Inertia không trực tiếp ép việc này xảy ra. Thông thường bạn cần dùng một kỹ thuật cache busting, chẳng hạn thêm query parameter phiên bản vào cuối URL của asset.

Với tích hợp Vite của Laravel, asset versioning được thực hiện tự động. Nếu dùng Laravel Mix, bạn cũng có thể tự động hóa việc này bằng cách bật [versioning](https://laravel.com/docs/mix#versioning-and-cache-busting) trong file `webpack.mix.js`.

## Làm mới thủ công

Nếu muốn tự kiểm soát việc refresh asset, bạn có thể trả về một giá trị cố định từ phương thức `version` trong middleware `HandleInertiaRequests`. Điều này tắt cơ chế asset versioning tự động của Inertia.

Ví dụ, nếu muốn thông báo cho người dùng khi frontend có phiên bản mới, bạn vẫn có thể đưa asset version thực tế lên frontend bằng cách thêm nó vào [shared data](/v2/data-props/shared-data).

```php
class HandleInertiaRequests extends Middleware
{
    public function version(Request $request)
    {
        return null;
    }

    public function share(Request $request)
    {
        return array_merge(parent::share($request), [
            'version' => parent::version($request),
        ]);
    }
}
```

Ở frontend, bạn có thể theo dõi thuộc tính `version` và hiển thị thông báo khi phát hiện phiên bản mới.
