## Có gì mới

Inertia.js v2.0 là một bước tiến rất lớn của Inertia! Core library đã được viết lại hoàn toàn về mặt kiến trúc để hỗ trợ asynchronous request, qua đó mở ra nhiều tính năng mới, bao gồm:

## Nâng cấp dependency

Để nâng cấp lên Inertia.js v2.0, trước tiên dùng npm để cài client-side adapter bạn muốn:

<CodeGroup>

```bash Vue icon="vuejs"
npm install @inertiajs/vue3@^2.0
```

```bash React icon="react"
npm install @inertiajs/react@^2.0
```

```bash Svelte icon="s"
npm install @inertiajs/svelte@^2.0
```

</CodeGroup>

Tiếp theo, nâng cấp package `inertiajs/inertia-laravel` để dùng nhánh dev `2.x`:

```bash
composer require inertiajs/inertia-laravel:^2.0
```

## Breaking changes

Mặc dù là một bản phát hành lớn, Inertia.js v2.0 không đưa ra quá nhiều breaking change. Dưới đây là toàn bộ thay đổi không tương thích ngược:

### Ngừng hỗ trợ Laravel 8 và 9

Laravel adapter hiện yêu cầu tối thiểu Laravel 10 và PHP 8.1.

### Ngừng hỗ trợ Vue 2

Adapter Vue 2 đã bị loại bỏ. Vue 2 kết thúc vòng đời vào ngày 3 tháng 12 năm 2023, vì vậy đây là thời điểm phù hợp để ngừng hỗ trợ.

### Phương thức `replace` của Router

Phương thức `router.replace` trước đây đã deprecated nay được khôi phục, nhưng chức năng đã thay đổi. Nó hiện được dùng để thực hiện [client-side visit](/v2/the-basics/manual-visits#client-side-visits). Để thực hiện server-side visit thay thế history entry hiện tại trong trình duyệt, hãy dùng tùy chọn `replace`:

```javascript
router.get('/users', { search: 'John' }, { replace: true })
```

### Svelte adapter

- Ngừng hỗ trợ Svelte 3 vì phiên bản này đã kết thúc vòng đời vào ngày 20 tháng 6 năm 2023.
- Helper `remember` được đổi tên thành `useRemember` để nhất quán với các helper khác.
- Callback `setup` trong `app.js` đã được cập nhật. Bạn cần truyền `props` khi khởi tạo component `App`. [Xem phần setup trong app.js](/v2/installation/client-side-setup#initialize-the-inertia-app)
- Callback `setup` giờ là bắt buộc trong `ssr.js`. [Xem phần setup trong ssr.js](/v2/advanced/server-side-rendering#add-server-entry-point)

### Partial reload giờ chạy bất đồng bộ

Trước đây partial reload trong Inertia chạy đồng bộ, giống mọi request Inertia khác. Trong v2.0, partial reload chuyển sang bất đồng bộ. Nhìn chung đây là hành vi mong muốn, nhưng nếu code của bạn phụ thuộc vào việc các request này chạy đồng bộ thì có thể cần điều chỉnh.
